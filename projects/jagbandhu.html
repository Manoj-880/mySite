JagBandhu

www.jagbandhu.com

Family platform spanning a Flutter mobile app and user/admin web apps — Family Tree, Events, Event Gallery, Circles, and User Storage.

Overview

JagBandhu is a family and community platform that helps extended families stay connected — mapping relationships as a family tree, organising events, sharing event galleries, forming private circles, and giving each member personal cloud storage. It ships as a Flutter mobile app with separate user and admin web applications.

What I did

  1. 01

    Owned the design system and product UX across the mobile app and both web apps.

  2. 02

    Built the interactive Family Tree, Events, Event Gallery, Circles, and User Storage modules.

  3. 03

    Developed the Flutter mobile client and the React user + admin web front-ends against a shared Node.js/Express API.

  4. 04

    Set up media storage and delivery on AWS and handled the production deployment.
